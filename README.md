## 总结

内容爬取与展示功能没问题，没有做导航、分页、分类等功能，因为差不多一本数和相关的章节就要占用5MB空间，云服务器空间有限，就没继续做下去了。

也没特别需要记录的，主要是空间问题，比如分类和来源，可以用一个数字来代替，但是我使用的是文字，但这不是占空间的主要原因，主要是一本书的章节内容太多。
